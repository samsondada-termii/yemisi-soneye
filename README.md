# Yemisi Soneye — local portfolio

A lightweight, nine-page static portfolio. No framework, production dependencies, external fonts, tracking or hosted image requests. Hosted on Vercel, connected to the GitHub repository.

## Run locally

Requires Node.js 18 or newer. In this folder:

```sh
npm run build
npm start
```

Open http://127.0.0.1:4173. The local server serves **only `dist/`**, keeping source notes, research and original files outside the website. If the existing preview is still running, use it rather than starting a second server on the same port.

`npm run dev` rebuilds and starts the server. After editing, run `npm run build` and refresh the browser. No installation is needed to build or run the delivered portfolio.

## Pages

- Home: introduction, selected work, capabilities and contact invitation.
- Work: the five-project index.
- Logos & heART: identity, campaign, editorial, exhibition system and live experience.
- EGFM / Who is Like God?: event environment and composition study, with no unverified edition date.
- Singlz Summit: 2024 campaign, circular scenic system and live applications.
- NLWC: layered scenery, vertical image composition and live views.
- Emmy Homes Realty: two property campaign applications.
- About: concise biography and capabilities.
- Contact: email enquiry link.

## Editing

- `content.mjs`: biography, project data and core case-study copy.
- `scripts/build.mjs`: page layouts, captions and supplementary presentation copy.
- `styles.css`: design and responsive layouts.
- `contact.config.json`: verified email; optional phone and profile fields remain null.
- `CONTENT.md`: collected copy for editorial review (regenerated by the build).
- `SOURCE-NOTES.md`: internal provenance, reconstruction decisions and exclusions.
- `assets/portfolio/`: prepared responsive WebP files; already included, no regeneration required.
- `assets/reconstructed/`: separate presentation assets, never overwriting originals.
- `assets/original/manifest.json`: inventory of untouched original folders and their dimensions.

Only `dist/` is a website deliverable. Do not host the workspace root.

## Verification

`npm test` checks all page entrypoints and internal asset/link references, and verifies research documents are excluded from the public output.

`scripts/qa.cjs` uses Playwright for browser checks and screenshots at 1440, 1280, 1024, 768, 430 and 390 pixels. Playwright was supplied by the workspace runtime; it is not required to run the site. Results are recorded in `QA-RESULTS.json` and `QA.md`. Full-page screenshots are in `screenshots/`.

`scripts/prepare-assets.cjs` is the optional image preparation utility (requires Sharp). The final prepared assets are included as files, so ordinary builds need only Node.js. The complete source/output mapping is in `assets/portfolio/manifest.json`.
